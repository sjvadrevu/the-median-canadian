# Data sources

Every dataset listed in the project's manifests, generated by `scripts/build_sources.py` from each `manifest.csv` (the machine-readable version is `data/sources.csv`). Each manifest holds fuller validation notes for its rows.

Download everything that has a plain file URL with `python scripts/download_data.py` (files go to `data/raw/` and are linked to the path the scripts read). Rows marked *fetch script* are downloaded by the named script, because they are queries or per-station or per-day requests. Rows marked *manual* are web pages, PDFs or services without a single-file URL (the manifest's own notes say how each was read). The script names come from a search of the repo's scripts for the URL or layer name, so treat them as a pointer, not a guarantee. *Snapshot in repo* rows are dated copies of live feeds kept in the repo, because the live feed cannot return the same numbers later.

## Licences

- Most federal data: Open Government Licence - Canada; Statistics Canada data: Statistics Canada Open Licence. Provincial data: the province's open government licence where one is stated; the manifests say where none was.
- **Microsoft Global ML Building Footprints are ODbL 1.0.** Any building data derived from them and published here (for example `analysis/losses/buildings_2026_near_outlines.gpkg` and the building counts in `analysis/losses/` and `analysis/property/`) is also made available under ODbL 1.0, with attribution to Microsoft.
- Copernicus Sentinel-2 data: Copernicus open data terms (contains modified Copernicus Sentinel data 2023 to 2026).
- Matz et al. 2026 supporting information (AQBAT coefficients): CC BY-NC 4.0, as recorded in the manifest.
- Where a licence cell says "(not in manifest)", the manifest had no licence column and the licence was filled from the publisher.

Row counts by status: derived 43, direct 111, fetch script 76, manual 85, not used 30, snapshot in repo 3.
